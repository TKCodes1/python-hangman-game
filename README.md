# python-hangman-game
A learning Python project where the player guesses letters to find the entire hidden word before the hangman is completed.

---

## 📙Features:
- Selects a random word from a library of 100 words.
- Win/loss conditions
- Hidden word that updates as you guess
- Duplicate letter detection
- ASCII hangman art

## 🧠What practiced and learned:
- Loops
- Dictionaries
- Sets
- Random module
- Functions
- User input

## ▶️How to run:
Make sure to have Python installed then run:
 
  ```bash
  python main.py
```
## How to play:
1. Guess one letter at a time.
2. Correct guesses reveal the slot they belong in, and incorrect letters draw another body part of the hangman.
3. Guess the word before hangman is fully drawn. (5 attempts)
